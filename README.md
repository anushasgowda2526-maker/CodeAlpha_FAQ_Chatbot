# CodeAlpha FAQ Chatbot

An intelligent FAQ chatbot that helps customers find answers to common questions using Natural Language Processing (NLP).

## Project Overview

The FAQ Assistant allows users to ask questions in natural language and retrieves the most relevant answers from a predefined FAQ knowledge base.

## Features

- Interactive customer-support chatbot
- NLP-based text preprocessing
- TF-IDF vectorization
- Cosine similarity matching
- Alternative question phrasing support
- FAQ search and category filtering
- Add, edit and delete FAQs
- Chat history and feedback
- Dashboard with usage analytics
- Fallback response for unrelated questions

## Technology Stack

- React
- TypeScript
- Vite
- Natural Language Processing (NLP)
- TF-IDF
- Cosine Similarity
- CSS

## Run Locally

**Prerequisite:** Install Node.js.

1. Clone the repository:

   `git clone https://github.com/anushasgowda2526-maker/CodeAlpha_FAQ_Chatbot.git`

2. Open the project folder:

   `cd CodeAlpha_FAQ_Chatbot/smart-faq-chatbot`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.
